# Two-phase runner construction

`create_campaign(root, manifest, prereg, schedule, configs, inputs, phase1, arm_files)` creates an exclusive local campaign directory. All supplied metadata is serialized and hashed, raw paths are explicit, and no arm/truth/custody discovery happens. `phase1` must satisfy archive.validate_phase1_metadata; dictionaries are released archive members, not embedded hidden context. Arm adapter configuration must contain separately admitted released dictionaries; they must not access truth. The runner never imports src/gen/arms or discovers providers. No runtime dispatch is authorized by this source.

Manifest: run_id, prereg_sha256 (`prereg_hash`), schedule_sha256 (`common.digest(schedule)`), configs_sha256 (`digest(configs)`), phase1_sha256, protocol_sha256, input_manifest_sha256 (`digest({case_id: raw_sha256})`), attempts and final_attempts. Each attempt has attempt_id/case_id/arm_id; IDs use letters/digits/underscore/hyphen. Final attempts name exactly one planned attempt per case/arm. Every planned optional repair must be retained explicitly, using a caller port returning outcome=skipped if unused; no recency selection. Manifest additionally pins arm_artifacts (per-arm logical filename/SHA256 mappings) and arm_entrypoints (module.qualified_function_name). arm_files maps each arm to exactly those logical names and explicit artifact paths. Prereg arms hash is digest of {schedule: sorted unique (arm_id, config_id) pairs, artifacts: arm_artifacts, entrypoints: arm_entrypoints, configs_sha256: digest(configs)}, input_manifest and protocol pins must agree. Schedule purpose/namespace rules come from denominators.py. Returned Campaign.expected is the external pin needed to reopen the same campaign with Campaign(root, expected).

`execute_replay` requires an explicit caller authorization boolean and offline_replay mode; every other mode refuses. This boolean is not proof of operator approval, rights, network isolation or port honesty; establish those externally before execution. Only ordinary source-backed functions with no closures are accepted; module/qualified name and source-file membership in the pinned artifact closure must agree. Artifacts are rehashed before each operation. This pins declared files, not completeness of transitive dependencies or Python globals/dynamic code; external admission and process isolation must establish the actual runtime closure. The port signature is `(raw_bytes, released_phase1_metadata, config) -> dict`, with explicit outcome from completed/error/timeout/no_output/unsupported/skipped. Completed results must embed a FHIR Bundle JSON object, never a bundle_path/output_path reference whose bytes could escape freezing. Callback result and any error attempt are retained under a durable exclusive reservation. Callback exceptions become error_type-only records; no credential-bearing exception text is retained. A crash after reservation leaves an incomplete campaign that cannot silently retry/freeze. Raw/config/result hashes are checked again. All outputs/dispositions supplied by the port remain in result. This is a runner boundary; concrete producer adapters belong to their owners.

`freeze(actor)` requires exactly all planned attempt outputs and reservations, including failures/repairs/skips across every scheduled arm. It records the complete attempt list hash and the full campaign hash. `open_and_score_once(truth_path, scorer, actor=..., expected_truth_sha256=..., expected_freeze_sha256=...)` verifies inputs/config/prereg/campaign/attempts before marking a single opening. Only then are bytes read from the explicit truth path and checked against the external seal. The scorer callback receives truth bytes and frozen attempt records. The exclusive marker is consumed even if loading/scoring fails; no same-set repair/tuning or repeat-open. The source does not attest H/O/Q admission, infer semantic success, or authorize live/held-out execution. Outputs explicitly retain independent_semantic_acceptance=false and runtime_verified=false.

This is a single-host filesystem protocol, not a sandbox/security proof. Separate custodians must enforce permissions, blindness, port isolation, complete inventories, signed admission and retired-set policy. A hostile process able to rewrite state/markers defeats local exclusivity; concurrent adversarial file mutation is not prevented by hash checks. No attempt files may be edited/deleted; preserve incomplete directories for external resolution. No archives or custody data were generated/read during construction.
