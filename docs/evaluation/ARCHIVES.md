# Phase-one archive boundary

`evaluation.archive.read_phase1_zip(archive_path, manifest, *, archive_sha256, max_member_bytes=2000000, max_total_bytes=20000000)` returns validated member bytes without extraction. The explicit manifest is a nonempty list of exact `{path, kind, sha256}` rows; kinds are metadata, raw, dictionary and onboarding. Expected hashes must originate in a separately admitted release. The reader cannot authenticate that release or issue admission GO.

Paths must be portable ASCII relative member paths under the matching metadata/, raw/, dictionary/ or onboarding/ prefix. Metadata/dictionary files use .json; raw/onboarding use .hl7. Traversal, absolute/drive/stream/hidden paths, Windows reserved names, trailing-dot aliases, case aliases, duplicate/truncated ZIP names, special/symlink/directory/encrypted members, unexpected/missing/unreferenced members, unsupported compression, and size/hash drift refuse. The selected archive and its parent paths must not be symlinks. No archive is extracted or generated by this module.

`validate_phase1_metadata(value)` accepts exactly `{schema_version: 1, cases: [...]}`. Each case has exactly case_id, site_id, raw_sha256, dictionary_sha256, message_path, dictionary_path, usage (scored/onboarding), and namespace (authored_fixture/offline_dev/heldout). Case IDs are unique within a metadata document. Input paths and hashes bind to manifested raw/onboarding and dictionary members. No latent record, atom assertions, oracle, expected outcome, profile or seed fields are supported.

`validate_dictionary(value)` supports the released developer dictionary shape only: dictionary_id, fixed provenance fields, codes/units/value_codes with system/code/display, identifier_systems, observation_statuses, report_statuses, coding_authorities and an empty z_segments map. Unknown fields and reconstructive key spellings refuse. Nonempty Z conventions need a later public contract before acceptance. Dictionary hash identity is not rights or semantic admission.

JSON object duplicate keys and nonfinite values refuse. Raw HL7/onboarding bytes are opaque: these checks do not prove that text or public dictionary values are free of hidden meaning, prompt injection or concealed reconstruction material. Independent H/Q release inspection, phase-one information policy and isolation remain required. Caller-supplied metadata may omit cases; archive structural closure cannot establish study completeness. Concurrent filesystem changes, Windows junction behavior, ZIP parser/resource edge cases and independent blindness remain runtime-unverified.

Dirty construction only. No archives or custody data were generated/read and no tests/imports/app execution occurred. Deferred checks include traversal/symlink/drive/alias negatives, ZIP duplicate/truncation/encryption/special member cases, all caps/hash mismatches, unknown JSON/reconstructive fields, missing/orphan reference members and released dictionary compatibility.
